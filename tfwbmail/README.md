# tfwbmail-app

Dit is de lokale PHP-webapp van tfwbmail. Starten kan via de Windows-launcher
`downloads/tfwbmail.exe`, `..\start-tfwbmail.bat` of Docker Compose vanuit de
repository-root.

De runtimegegevens staan in `data/` en blijven lokaal. Zie de [hoofddocumentatie](../README.md)
voor installatie, IMAP/SMTP, Stalwart, TLS, back-ups en probleemoplossing.
